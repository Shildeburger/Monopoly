Онлайн-версия настольной «Монополии» с игрой в реальном времени между несколькими игроками.

Стек: Laravel + Inertia + Vue, PostgreSQL, Laravel Reverb для веб-сокетов — состояние доски синхронизируется между игроками без перезагрузки страницы. Окружение поднимается через Docker и devcontainer одной командой.
